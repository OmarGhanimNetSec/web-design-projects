\# Web Design Projects



Frontend HTML, Bootstrap, and JavaScript exercises and interactive pages.



\## Repository Structure



\### `api-dashboards/`

\- `Airport-Live-Tracking-1.html` — Live departure and active flight tracker using the Aviationstack API with FlightRadar24 links\[cite: 8].

\- `bahrain-open-data-1.html` — Higher education institutions table fetching records from Bahrain Open Data (`data.gov.bh`)\[cite: 9].



\### `ui-and-forms/`

\- `calculator.html` — Bootstrap calculator layout with basic arithmetic operations\[cite: 10].

\- `tables.html` — Bootstrap table styling progression (`table-bordered`, `table-striped`, `table-hover`, `table-dark`)\[cite: 12].

\- `Registration.html` — Student registration form built with Bootstrap grid and form controls\[cite: 13].

\- `login.html` — Login form UI using Bootstrap classes\[cite: 14].

\- `index-2.html` — Bootstrap responsive column and container layout example\[cite: 15].



\### `mini-games/`

\- `Fruit-Game.html` — Spin-and-match fruit game with selectable speed intervals and win/loss counters\[cite: 7].



\## How to Run



Open any `.html` file directly in a web browser (using a local server is recommended for pages that fetch external APIs).
